# Personal Portfolio

This is a personal portfolio website.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Editing Content

All content lives in `data/`; the components only render it.

- `data/experience.ts` and `data/organizations.ts` — rows on the home page
- `data/projects.ts` — projects, in display order
- `data/site.ts` — nav links, social links, and the resume path (the PDF itself is in `public/resume/`)
